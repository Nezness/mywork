## 1. 本トピックの核を一枚で

### 1.1 動機

| 観点 | 結論 |
|------|------|
| 回転磁界 | 空間 120°・時間 120° から振幅一定の円形回転磁界が自然に出る(01 節) |
| 送電経済性 | 同一電力・電圧・力率で導体量が単相の約 87%(01 節) |
| 動力・電源の平坦性 | 平衡時に瞬時電力が時間に依らず一定(04 節) |

### 1.2 回路技術

| 項目 | 関係式 |
|------|--------|
| 相電圧 ↔ 線間電圧(Y) | $\dot V_L = \sqrt 3\,\dot E_p\angle{+30^\circ}$ |
| 相電流 ↔ 線電流(Δ) | $\dot I_L = \sqrt 3\,\dot I_p\angle{-30^\circ}$ |
| Y ↔ Δ(平衡) | $\dot Z_\Delta = 3\dot Z_Y$ |
| 三相合計電力 | $P_{3\phi} = \sqrt 3\,V_L I_L\cos\theta = 3 V_p I_p\cos\theta$ |
| 複素電力 | $\dot S_{3\phi} = 3\dot V_p\,\overline{\dot I_p} = P_{3\phi} + jQ_{3\phi}$ |
| 1 相分等価の根拠 | 平衡時 $\dot V_{NN'} = 0$ |

### 1.3 不平衡の入口

| 項目 | 要点 |
|------|------|
| $\alpha$ 演算子 | $\alpha = e^{j2\pi/3}$、$1 + \alpha + \alpha^2 = 0$ |
| 対称座標分解 | 任意の三相量 = 正相 + 逆相 + 零相 |
| 平衡の正体 | 正相成分のみが有限、$\dot X_1 \ne 0$、$\dot X_0 = \dot X_2 = 0$ |
| 対称行列の対角化 | 対称座標で見ると 3 系統が独立になり、故障解析を単相問題に還元可能 |

## 2. 他科目への接続

### 2.1 機械

- **誘導機**: 固定子三相巻線が作る回転磁界(01 節)がそのまま滑り速度・トルク特性の解析基盤となる。
- **同期機**: 三相起電力(02 節)の生成原理と、電機子反作用・同期リアクタンスの解釈で対称座標が活きる。
- **変圧器**: 三相変圧器の Y-Y、Y-Δ、Δ-Δ 各結線で、線間/相量の √3・30° 関係(03 節)と、零相電流の経路(06 節)が直結する。

### 2.2 電力

- **送電**: 三相送電の経済性(01 節)、短距離・中距離・長距離線路の等価回路(1 相分)、潮流計算。
- **故障解析**: 1 線地絡・2 線短絡・3 線短絡の各故障を対称座標(06 節予告)で統一的に扱う。
- **保護**: 差動保護・距離保護・地絡保護の動作原理に正相/逆相/零相の分離が直接現れる。
- **電力品質**: 電圧不平衡率(07 節問 3)、高調波(04 節 Note)。

### 2.3 法規

- **技術基準**: 発電・変電・送電における電圧区分、接地方式、絶縁協調の議論に本トピックの「相電圧 vs 線間電圧」「中性点接地と零相」の感覚が必要。
- **電気事業法**・**電技解釈**: 絶縁距離・接地抵抗値・保護協調の根拠として、本トピックの結果が常識として引かれる。

## 3. 一種で深掘りされる箇所(再掲)

本トピック中に張った「一種への伏線」を再確認:

1. **単一周波数近似の限界**(00 節): 過渡・非正弦・高調波ではラプラス変換や対称座標+シーケンス周波数解析へ。
2. **楕円磁界**(01 節): 円形回転磁界が崩れた状況は、二相運転や不平衡運転の解析で深掘りされる。
3. **絶縁耐力で律速**(01 節): 相電圧基準の送電比較は一種電力の論述頻出。
4. **瞬時電力一定の破れ**(04 節): 不平衡・非正弦波での高調波電力解析。
5. **ねん架の対称化**(05 節): 送電線の相互インダクタンス、非対称線路の正しい扱い。
6. **対称座標法の系統別回路**(06 節): 故障条件を対称座標で翻訳し、正相・逆相・零相の等価回路の直列・並列構成として解く技法 — 一種電力・機械の中核。

## 4. 応用・記述(3 層モデル第 3 層)への橋渡し

二次試験・一種論述では「平衡から不平衡へ、対称座標で故障解析」というストーリーラインが最頻出。本トピックの 06 節をフル展開した応用ノードとして、以下を後続トピックに予定:

- `symmetrical-components`: 正相・逆相・零相成分の代数と変換行列の性質(本節で予告した $\alpha$ 演算子の深掘り)。
- `sequence-impedance`: 発電機・変圧器・送電線の正相/逆相/零相インピーダンスと、変圧器結線ごとの零相経路。
- `fault-analysis-basic`: 1 線地絡・2 線短絡・3 線短絡を対称座標で統一的に。
- `per-unit-system`: 系統規模の計算を基準化して扱う単位法。

本トピックから最短でたどる場合は `three-phase-ac` → `symmetrical-components` → `sequence-impedance` → `fault-analysis-basic`。
